# AI-powered Apps

This repository contains projects and practice work from the **IBM AI Developer Professional Certificate** course on Coursera.

## About this repository

These projects were completed while I was learning how AI-powered applications are built with Python and related AI tools.

Important note: most of the starter code was provided as part of the Coursera / IBM course materials. My work was mainly to:

- read and understand the provided code
- analyze how the application was structured
- complete the missing parts
- test the apps and fix issues
- learn how Python and AI services work together in real projects

Because of that, this repository is not meant to show that every line of code was written from scratch by me. It is a learning portfolio showing my progress while studying AI development.

## What I practiced

- Python basics in real application code
- working with APIs
- using AI models and services
- understanding existing code
- completing partially built projects
- debugging and testing small applications

## Course context

The code in this repository is connected to hands-on labs and assignments from the IBM AI Developer course on Coursera. The original project ideas and much of the code structure came from the course materials.

## How to use

Each project may have its own setup steps. In general, you may need to:

1. Clone the repository.
2. Open the project folder you want to run.
3. Install the required Python packages.
4. Add any needed API keys or environment variables.
5. Run the main Python file or app command.

Example:

```bash
pip install -r requirements.txt
python app.py
```

The exact command may be different for each project.
